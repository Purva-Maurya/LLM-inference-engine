A lightweight LLM inference engine built from scratch in Python, designed to understand and implement the core components behind modern Transformer-based language model inference.

The project focuses on understanding what happens inside an LLM during inference — from converting tokens into embeddings, through Transformer layers and causal self-attention, to generating the next token using different sampling strategies.

The goal is not to build another wrapper around an existing inference library, but to implement and understand the inference process at a low level.
